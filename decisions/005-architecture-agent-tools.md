# ADR-005 · architecture · Инструменты агента и внешние источники

TravelAgent получает несколько типов инструментов. Tutu MCP даёт реальные
варианты поездок и отелей. Hosted web search используется для внешних фактов.
Weather tool и difference tool реализуем как локальные function tools на
TypeScript. Модель выбирает, какой инструмент нужен, а код валидирует вход и
возвращает структурированный результат.

## Что ещё рассматривали

- Все источники завернуть в собственный gateway. Это уменьшает свободу агента и
  возвращает ручную маршрутизацию.
- Дать виджету прямой доступ к Tutu MCP и погоде. Так нельзя: ключи, лимиты,
  ошибки и нормализация должны оставаться на сервере.
- Сразу писать отдельный MCP-сервер для каждого локального инструмента. Для
  первого слайса function tools проще. MCP можно добавить, когда инструменты
  понадобятся нескольким агентам.

## Последствия

- Tutu MCP — источник вариантов, но не формат UI.
- Raw ответы внешних источников нормализуются до нашей модели.
- `difference.compare` считает числа кодом, а не текстом модели.
- Для Tutu используем осторожный режим: мало вызовов, без автоматического долбежа
  endpoint и без параллельного перебора всех вариантов.
