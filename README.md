# Сколько на самом деле стоит ваша поездка?

Намного больше, чем цифра на билете. Ночной рейс может потребовать такси до
отеля, а долгая пересадка —
отнять весь день. Вариант подороже часто оказывается выгоднее, если учесть все
скрытые расходы и удобство маршрута.

**Туту Разница** подсвечивает эти нюансы ещё до покупки.

<a href="https://tutu.apps.botops.ru/" target="_blank" rel="noopener noreferrer">Посмотреть демо</a> *(открыть в новой вкладке: Ctrl/Cmd+клик)*

## Как это работает

1. **Запрос:** Вы пишете в виджет, куда едете и что важно — дата, бюджет, багаж,
   избегать ли ночных рейсов или подстроить поездку под концерт.
2. **Анализ:** Система собирает варианты, а AI простым языком объясняет, где скрыты
   переплаты, лишнее время в пути или неудобные стыковки.
3. **Корректировка:** Условия можно менять прямо в диалоге — подборка и рекомендации
   сразу обновятся.

> **Пример:** Билет дешевле на 1 360 ₽, но прилёт ночью потребует такси за 1 500 ₽.
> Виджет покажет это сразу, чтобы экономия была реальной, а не только на экране.

## Что доступно в демо

Без query-параметров открывается компактный чат **«Сценарий»** на шаге
**«Реальная разница»**. Это не live-поиск: варианты один раз сохранены из Tutu
MCP 19 августа 2026 и воспроизводятся без сети. Шесть шагов постепенно
раскрывают запрос, загрузку, последствия и пересчёт; новое условие «не
отправляться ночью» применяется кодом.

Вкладка **«Свой запрос»** запускает живой Node API → TravelRun → TravelAgent →
Tutu MCP и получает результат через SSE. Переключение вкладок не сбрасывает
live-сессию. Покупку билета пока не делаем.

## Разработка

```bash
pnpm install
cp .env.example .env
# заполнить OPENAI_API_KEY в .env
pnpm dev
pnpm build
```

Обновить snapshot до даты поездки можно только вручную:

```bash
pnpm exec tsx src/scenario/capture-presentation-snapshot.ts --date 2026-09-05
```

Capture не перезаписывает `snapshots/presentation-source.json`: для осознанного
обновления сначала сохраните или уберите прежний файл. При ошибке повторять
запрос автоматически нельзя. После проверки source snapshot нормализованные
значения обновляются в `src/scenario/`; только они попадают во frontend.

В режиме разработки виджет доступен на <http://127.0.0.1:5173>, API — на
`http://127.0.0.1:8787`. `TUTU_MCP_URL` по умолчанию равен официальному endpoint
из `.env.example`.
