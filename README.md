# Сколько на самом деле стоит ваша поездка?

Намного больше, чем цифра на билете. Ночной рейс может потребовать такси до
отеля, а долгая пересадка — отнять весь день. Вариант подороже часто оказывается
выгоднее, если учесть скрытые расходы и удобство маршрута.

**Туту Разница** подсвечивает эти нюансы ещё до покупки.

<a href="https://tutu.apps.botops.ru/" target="_blank" rel="noopener noreferrer">Посмотреть демо</a> *(открыть в новой вкладке: Ctrl/Cmd+клик)*

## Как это работает

1. **Лендинг объясняет контекст:** маршрут, событие, источник данных, числовую
   разницу и ограничения сценария.
2. **Виджет собирает действие:** маршрут, дату, условия, карточки вариантов,
   уточнение и рекомендацию.
3. **Live-режим проверяет свой маршрут:** существующий Node API запускает
   TravelRun, агент вызывает Tutu MCP, а frontend получает события через SSE.

> **Пример:** Билет дешевле на 414,81 ₽, но отправление в 01:35 может быть
> неудобным. Лендинг показывает происхождение данных и расчёт, а виджет оставляет
> рядом только карточки, progress и короткое действие.

## Что доступно в демо

Без query-параметров открывается режим **«Сценарий»** на шаге **«Реальная
разница»**. Это не live-поиск: варианты один раз сохранены из Tutu MCP 19
августа 2026 и воспроизводятся без сети. Шесть шагов раскрывают запрос,
варианты, последствия, числовую разницу, новое условие и рекомендацию.

Демо разделено на две зоны:

- слева — лендинг с объяснением продукта, source snapshot, сценарием и шагами;
- справа — минимальный виджет, который можно свернуть в компактную карточку и
  снова развернуть.

Вкладка **«Свой запрос»** запускает живой Node API → TravelRun → TravelAgent →
Tutu MCP и получает результат через SSE. API-контур в этой правке не менялся.
Покупку билета пока не делаем.

## Разработка

```bash
pnpm install
cp .env.example .env
# заполнить OPENAI_API_KEY в .env
pnpm dev
pnpm build
```

Обновить snapshot до даты поездки можно только вручную:

```bash
pnpm exec tsx src/scenario/capture-presentation-snapshot.ts --date 2026-09-05
```

Capture не перезаписывает `snapshots/presentation-source.json`: для осознанного
обновления сначала сохраните или уберите прежний файл. При ошибке повторять
запрос автоматически нельзя. После проверки source snapshot нормализованные
значения обновляются в `src/scenario/`; только они попадают во frontend.

В режиме разработки виджет доступен на <http://127.0.0.1:5173>, API — на
`http://127.0.0.1:8787`. `TUTU_MCP_URL` по умолчанию равен официальному endpoint
из `.env.example`.
